# Шаг 2 — спрятать API-ключ и включить списание ходов

После этого шага твой OpenRouter-ключ живёт ТОЛЬКО на сервере Supabase, а в браузере
его больше нет. Каждый ход игрока проходит через твою серверную функцию, которая
проверяет вход и списывает 1 ход. Всё делается в браузере, командная строка не нужна.

## Часть 1. Положить секретный ключ на сервер

1. Supabase → **Edge Functions** (слева) → вкладка **Secrets** (или **Manage secrets**).
2. **Add new secret**:
   - Name: `OPENROUTER_KEY`
   - Value: твой ключ OpenRouter (`sk-or-...`)
3. **Save**.

> `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` уже есть на сервере
> автоматически — добавлять их не нужно. Свой личный ключ OpenRouter ты кладёшь ТОЛЬКО сюда,
> в `config.js` браузера его быть не должно.

## Часть 2. Создать функцию «ai»

1. Supabase → **Edge Functions** → **Create a function** (или **Deploy a new function**).
2. Имя функции — ровно **`ai`** (маленькими буквами).
3. Откроется редактор кода прямо в браузере. Удали всё, что там есть по умолчанию.
4. Открой файл `supabase/functions/ai/index.ts` из этого репозитория, скопируй **весь** код,
   вставь в редактор.
5. **ВАЖНО:** найди настройку **Verify JWT** у этой функции и **выключи её** (Off).
   (Проверку входа игрока функция делает сама внутри; без выключения не пройдёт CORS.)
6. Нажми **Deploy**.

Функция получит адрес вида `https://ТВОЙ-ПРОЕКТ.supabase.co/functions/v1/ai` —
игра подставляет его автоматически, вручную вписывать не нужно.

## Часть 3. Обновить файлы игры в GitHub

Замени в репозитории три файла на новые версии:
- `config.js` (сам вычисляет адрес сервера)
- `ai.js` (вызовы ИИ идут через прокси; запрос ключа в браузере убран)
- и добавь папку `supabase/functions/ai/index.ts` (для истории; на работу игры не влияет).

Подожди ~1 минуту, пока GitHub Pages обновится. Обнови игру (Ctrl+F5).

## Что проверить

1. Открой игру и **войди** в аккаунт (по почте или Google).
2. Начни партию, нажми **«Следующий ход ▶»**.
3. Новости должны прийти как обычно — но теперь их сгенерировал твой сервер.
4. Счётчик в углу **🎲 40 → 39** уменьшился на 1. Значит, списание работает.
5. Открой **F12 → вкладка Network**: запрос уходит на `.../functions/v1/ai`, а НЕ напрямую
   на openrouter.ai. Ключа `sk-or-...` нигде в браузере не видно. ✅

### Если кончились ходы
Когда баланс дойдёт до 0, вместо новостей появится «⛔ Ходы закончились». Это нормально —
начисление и покупка ходов появятся на **шаге 3 (оплата Stripe)**. Пока для теста можно
вручную добавить себе ходов: Supabase → **Table Editor → profiles** → своя строка →
поле `turns_balance` → поставь, например, 200 → сохранить.

## Сколько это стоит тебе
На модели `gemini-3.1-flash-lite` один ход ≈ 0,15–0,3 цента. Портреты (картинки) —
дороже, поэтому они включены только для плана `premium` (ставится на шаге 3).

## Как проверить, что ключ действительно спрятан
- **F12 → Network** во время хода: нет прямых запросов на `openrouter.ai`, только на твой `.../functions/v1/ai`.
- **F12 → Application → Local Storage:** нет `openrouter_key`.
- Всё, что видит браузер — публичный anon-ключ Supabase, он безопасен.
