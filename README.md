# Grand Strategy

Браузерная политическая стратегия: игрок управляет государством обычными текстовыми приказами. ИИ интерпретирует намерения, выбирает политические действия и пишет газету; движок проверяет деньги, людей, географию, сроки и согласие сторон.

**Актуальная игра для телефона и ноутбука:** [открыть](https://zhank478.github.io/grand-strategy/). Главный вход `index.html` открывает `economy-world.html`. Стартовый сценарий — «Мир 1852 — приказы». Другие экспериментальные страницы не являются актуальным входом.

Старая версия для сравнения: [desktop-legacy.html](desktop-legacy.html). Её экономика и ИИ отличаются от текущей игры.

## Запуск

Используйте GitHub Pages или локальный HTTP-сервер (`python3 -m http.server`). Откройте корневую страницу. Гостевая сессия работает через Supabase; собственный ключ OpenRouter для гостевого запуска не нужен. Доступ к серверному ИИ требует настроенного проекта Supabase и доступных гостевых ходов.

## Устройство игры

- Карта и страны берутся из сценария; редактор сохраняет пользовательские сценарии.
- Приказы исполняются при ходе. Длинные программы продолжаются по игровому календарю.
- Иностранные кабинеты имеют цели, память и собственные решения; договор требует согласия адресата.
- Экономика считает производство, бюджет, расходы, долг и демографию. Деньги отображаются в миллионах расчётных единиц.
- Армия и флот используют существующих людей, корабли, маршруты и снабжение. Флоту можно поручать цели текстом.
- Газета показывает подтверждённые решения и реакции. Численные последствия раскрываются под статьями.
- Техническая ошибка интерпретации сохраняет поручение для повтора, не запрещая течение времени.
- Сохранение хранится локально; облачное сохранение использует Supabase и сохраняет дробную казну.

## Проверки

Бесплатные проверки движков и Chromium запускаются в GitHub Actions. Платные испытания выделены в одноразовый workflow с отдельным лимитом; их нельзя автоматически повторять в обычном CI. Результаты живых партий и ограничения проверки публикуются отдельно.
