# Grand Strategy

Браузерная стратегическая игра с ИИ-симуляцией мира. Страны, карты и сценарии — полностью
динамические: никакого хардкода списка стран.

## Структура проекта

```
grand-strategy/
├── index.html          — главная страница (весь интерфейс)
├── map.js              — карта, реестр сценариев, провинции, зум, объекты на карте
├── game.js             — страны из сценария, экономика (бюджет/долг/инфляция),
│                         провинциальные доходы, возраст правителей, ходы, сохранения
├── ai.js               — ИИ: события мира, внутренние новости, breaking news, дипломатия,
│                         профили стран (правители/интересы/парламент), портреты правителей
├── ui.js               — панели, попапы, парламент, breaking-экран, меню сценариев
├── editor.js           — редактор карт и сценариев (любые страны, свободный ввод)
├── scenario_1852.json  — встроенный сценарий «Европа 1852»
└── README.md
```

## Как запустить локально

Открой `index.html` в браузере (лучше через локальный сервер: `python3 -m http.server`).
При первом запуске игра спросит OpenRouter API ключ.

## Ключевые механики

- **Сценарии без хардкода** — список стран берётся из владельцев провинций активного
  сценария. Редактор: нарисуй/импортируй карту → «Создать сценарий» → введи ЛЮБЫЕ страны
  свободным текстом → «Сохранить сценарий в игру». В меню «🎲 Сценарии» он станет доступен.
- **ИИ-профили стран** — для стран без встроенных данных ИИ придумывает правителя (с возрастом),
  форму правления, показатели, описание и национальные ИНТЕРЕСЫ под год сценария.
- **Субъектность стран** — каждая страна действует по своим интересам; между ИИ-странами
  ведутся СКРЫТЫЕ отношения и войны, которых игрок не видит.
- **Скрытая информация** — игрок не видит казну/армию/стабильность чужих стран, только
  отношения; о чужих делах он узнаёт из новостей и переговоров.
- **Экономика** — доход складывается из провинций (захват провинции реально двигает доход),
  расходы: содержание армии и проценты по долгу; дефицит покрывается займами, долг разгоняет
  инфляцию, инфляция и долг бьют по стабильности. ИИ получает реальные числа бюджета.
- **Правители стареют и умирают** — возраст растёт, шанс смерти растёт с возрастом;
  преемника назначает ИИ (с возрастом), иначе — регентство. Статусы персоны убираются с карты.
- **Парламент** — динамические фракции и поддержка правительства; низкая поддержка
  подтачивает стабильность; события двигают расклад.
- **Новости** — 10 мировых + 3 внутренние (по провинциям/бюджету/парламенту) каждый ход;
  редкие катастрофические события выводятся на большой экран (breaking news).
- **Портреты правителей** — генерируются ИИ (модель изображений через OpenRouter),
  автоматически при смене правителя или кнопкой; отключается в настройках.

## Как запустить через GitHub Pages

1. Залей репозиторий на GitHub
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`
3. Игра будет доступна по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ`
