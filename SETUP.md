# Настройка бэкенда — Шаг 1: аккаунты и профили

Этот шаг включает вход по почте, профили игроков, баланс ходов и облачные сейвы.
Прокси API-ключа и оплата — следующие шаги (см. «Дальше»).

## 1. Создать проект Supabase (бесплатно)

1. Зайди на https://supabase.com → **New project** (нужен только email/GitHub-вход).
2. Дай имя, придумай пароль базы, выбери ближайший регион → **Create**.
3. Тариф **Free** — ничего платить не нужно.

## 2. Создать таблицы

1. В проекте: **SQL Editor** → **New query**.
2. Открой файл `supabase/schema.sql` из этого репозитория, скопируй всё, вставь → **Run**.
3. Должно выполниться без ошибок. Появятся таблицы `profiles` и `saves` и функции `spend_turn`, `add_turns`.

## 3. Включить вход по email

1. **Authentication → Providers → Email** → включён по умолчанию (magic link). Готово.
2. (Опционально) **Google**: включи провайдер Google и вставь OAuth-ключи из Google Cloud — тогда заработает кнопка «Войти через Google». Без этого игра прекрасно работает на magic link.
3. **Authentication → URL Configuration → Site URL**: впиши адрес, где будет крутиться игра
   (для локального теста — `http://localhost:8000`; позже — адрес на хостинге).

## 4. Вписать ключи в игру

1. **Project Settings → API**. Скопируй:
   - **Project URL** (вида `https://xxxx.supabase.co`)
   - **anon public** ключ
2. Открой `config.js` и вставь их вместо `__SUPABASE_URL__` и `__SUPABASE_ANON_KEY__`.

> anon-ключ **публичный** и безопасен в браузере — данные защищают политики RLS из `schema.sql`
> (каждый видит только свои строки). Секретный `service_role` ключ в браузер **не клади** — он
> понадобится только на сервере-прокси (шаг 2).

## 5. Запустить

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000`. Теперь перед игрой — экран входа. Введи почту → получи ссылку →
перейди по ней → ты в игре. В углу появится плашка с почтой и балансом ходов (🎲 40 на старте).
Сохранения теперь дублируются в облако (таблица `saves`).

Пока `config.js` не заполнен, игра работает по-старому (без входа) — ничего не ломается.

## Дальше

- **Шаг 2 — прокси ключа + списание ходов:** Edge Function, которая держит твой OpenRouter
  ключ на сервере, проверяет вход, вызывает `spend_turn`, ходит в OpenRouter. Тогда ключ
  исчезает из браузера (`ai.js`) полностью.
- **Шаг 3 — оплата (Stripe):** Checkout + webhook, который вызывает `add_turns` и начисляет
  купленные ходы. Премиум-план включает портреты/иллюстрации.
