# Экспериментальная мобильная версия

Откройте `mobile.html` через тот же HTTP-сервер, что и обычную игру.
Например, после публикации этих файлов на GitHub Pages:
`https://zhank478.github.io/grand-strategy/mobile.html`.

Это отдельная точка входа, использующая существующие игровые скрипты, карты,
аккаунты и сохранения. При открытии на том же домене сохранения общие с
обычной версией. Основная страница `index.html` не изменена.

## Управление

- В главном меню можно выбрать страну из списка или касанием карты.
- Один палец перемещает карту, два пальца меняют масштаб.
- Кнопки +, − и ⌂ позволяют изменить масштаб и вернуть обзор мира.
- Стрелка слева открывает досье страны.
- Нижняя панель содержит действия, дипломатию, советника и следующий ход.
  На узком экране панель прокручивается; в горизонтальном положении — по горизонтали.
- Всплывающие панели открываются по одной; крестик закрывает текущую.

## Проверка на устройстве

Проверить Safari iOS и Chrome Android в вертикальной и горизонтальной ориентации:
выбор сценария и страны, касание чужой провинции, перемещение без случайного
выбора страны, масштаб двумя пальцами, досье, дипломатия, ввод с экранной
клавиатурой, следующий ход, новости и повторная загрузка сохранения.

Проведена проверка синтаксиса нового JavaScript и ссылок на локальные ресурсы.
Визуальная проверка в браузере и на физическом телефоне ещё не проведена.
Редактор: касание добавляет точку или выбирает область; карандаш рисует пальцем,
режим выделения поддерживает рамку. Два пальца перемещают/масштабируют холст;
кнопка ✋ включает перемещение одним пальцем, «Готово» завершает рисунок,
«Панель» скрывает/показывает инструменты. Проверить эти действия на телефоне. ИИ требует интернет и существующую
настройку ключа/аккаунта.

`mobile.html` — копия интерфейса основной страницы. При будущих изменениях
разметки в `index.html` соответствующие изменения нужно переносить сюда.
