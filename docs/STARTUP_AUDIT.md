# Проверка запуска тестовой версии — 2 октября 2026

Страница: core-loop.html. Отчёт отделяет подтверждённый код от непроверенного браузера и сервера.
Ссылка после публикации: https://zhank478.github.io/grand-strategy/core-loop.html?v=3

## Какой сценарий

По умолчанию builtin-world → scenario_mr4rhxpc.json, «Мир 1852».
Файл 918 579 байт, 672 провинции, 48 стран, 44 604 координатных точки.
Игра помнит последний выбор в gs1852_active_scenario; сохранение партии также содержит свой scenarioRef.
Поэтому конкретный браузер может загружать другой встроенный или пользовательский сценарий.
Встроенные 1912/2016 имеют размер около 3,4 МБ каждый.
Старый «компактный» scenario_1852.json фактически 7 614 688 байт, больше основного мира.
Ранее при ошибке любого сценария код автоматически загружал именно этот большой файл.

## Что делал ИИ

До начала партии загрузка карты читает готовый JSON, ИИ не рисует границы.
resetGame/loadGameSlot запускают queueMissingProfiles: раньше все недостающие профили плюс agenda остальных стран.
Названия текущего мира совпадают со старым COUNTRY_DEFAULTS только у 1 из 48 стран.
Это означало 47 полных профилей партиями до 10 и 1 запрос интересов: всего 6 текстовых запросов.
Данные ИИ могли позднее менять стартовые деньги/армию и повторно инициализировать экономику.
cost=0 не делает запросы OpenRouter бесплатными. Текущий исходник прокси аккаунта также списывает 1 игровой ход независимо от cost.

Теперь в тестовой версии AUTO_GENERATE_WORLD_PROFILES=false: автоматический старт не вызывает подготовку мира.
Используются существующие базовые/предварительные данные игры. Это не означает, что все 48 профилей стали исторически точными.
Явный вызов queueMissingProfiles([countryId]) может подготовить только указанные страны.
В обычном ходе ИИ получает сводки: при более 30 странах отбираются до 26 релевантных; география и экономика не создаются заново целиком.
Эта доработка не меняет основной цикл и правила последствий приказов.

## Что исправлено на тестовой странице

- D3 7.8.5 поставляется из vendor/d3.v7.min.js; версия сохранена, зависимость от внешнего CDN при запуске карты убрана.
- Supabase SDK и TopoJSON редактора загружаются асинхронно. Карта не ждёт авторизацию.
- После поздней загрузки SDK серверное подключение повторяется без отключения уже введённого собственного ключа.
- У загрузки сценария таймаут 15 секунд, статус загрузки/построения/готовности, повтор и явный выбор «Мир 1852».
- Ошибка не запускает молча более тяжёлый старый сценарий.
- Измерение надписей Canvas заменяет повторные getComputedTextLength с записью SVG между измерениями.
  Правила размера/регионов и сама геометрия остаются прежними; реальные метрики шрифта могут немного отличаться.
- Список стран обновляется по завершению загрузки вместо опроса каждые 700 мс.
- Неисправная карта не активирует стартовую кнопку.
- Основные index.html/mobile.html и их движок этим обновлением не изменены.

## Подготовка Supabase, пока НЕ применена к серверу

1. Подтвердить доступ через подключение Supabase и сопоставить проект с SUPABASE_URL.
2. Проверить журналы Anonymous Sign-in, настройки анонимного входа, существование функций ai/guest-ai и гостевых RPC.
3. Применить недостающие таблицы/RPC из supabase/mobile_guest.sql. Не сбрасывать существующие счётчики и профили.
4. Развернуть guest-ai с собственной проверкой JWT; шлюз не должен отклонять токен до кода функции.
5. Функция использует существующий OPENROUTER_KEY, не возвращает его браузеру.
6. Новый status сообщает guest_models. Подготовленный список: Gemini Flash Lite, Luna, FlashX, GLM 5.3.
7. Для Sonnet задать GS_SONNET_MODEL только после подтверждения точного ID по каталогу.
8. Развернуть исправление CORS для ai: браузер отправляет apikey, старый исходник разрешал лишь authorization/content-type.
9. Проверить status и один настоящий ход с выбранной моделью. По ответу проверить фактический ID и расход.

Наличие секретного ключа, настройки auth, миграции и развёрнутые функции в этой сессии не проверены.
Источник гостевой функции обновлён в репозитории; публикация GitHub Pages не развёртывает Edge Functions.
Старый guest-ai, не возвращающий guest_models, остаётся для клиента ограниченным Gemini.
Новая функция разрешает только явный серверный список; произвольные модели запросом клиента не разрешаются.
Supabase не был подключён на момент публикации, поэтому серверная настройка остаётся незавершённой.

## Проверки

- Синтаксис JavaScript.
- Реальная D3 7.8.5 обработала все 672 геометрии и построила 55 региональных размещений названий.
- Измерение названий на моках не обращается к SVG getComputedTextLength.
- Загрузка: успешные стадии, сетевая ошибка без большого fallback, таймаут, пользовательский сценарий, отказ при отсутствии геометрии.
- Ноль запросов подготовки профилей при старте; явный запрос одной страны затрагивает только её.
- Сервер на моках возвращает разрешённые модели, отклоняет неизвестную до платного вызова и пересылает Luna в OpenRouter.
- Настоящего браузера/профилировщика, оплаченных генераций и доступа к установленному Supabase здесь не было.

Таким образом выявлены и исправлены конкретные источники задержки, но точная причина вылета браузера пользователя пока не подтверждена.
