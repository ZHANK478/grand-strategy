# Подключение ИИ в тестовой версии

Обновление 2 октября 2026 года после ошибки guest_unavailable.
Публичная тестовая страница: https://zhank478.github.io/grand-strategy/core-loop.html?v=2

Страница больше не загружает mobile-session.js. Использует experimental-session.js:
- повторяет подключение по кнопке, показывает понятную причину вместо guest_unavailable;
- сохраняет необязательный вход через существующие функции Supabase;
- позволяет подключить собственный ключ OpenRouter в поле «Подключение ИИ»;
- проверяет ключ через /api/v1/auth/key без запроса генерации;
- хранит введённый ключ только в памяти страницы, очищает поле после проверки, не записывает ключ в localStorage/репозиторий/журнал;
- посылает выбранный ID напрямую в OpenRouter при подключённом собственном ключе;
- не подменяет Luna гостевым Gemini: блокирует неподдерживаемый выбор до резервирования гостевого хода;
- показывает ID последнего ответа при прямом подключении.

После обновления страницы собственный ключ нужно подключить снова. Ранее сохранённый браузерный ключ автоматически не импортируется.
Серверный ключ Supabase не считывается и не передаётся браузеру.
Наличие токена аккаунта не доказывает работоспособность серверной функции; ошибка её запроса будет показана отдельно.
Вход через email/Google зависит от существующих настроек Supabase и разрешённых redirect URL.

core-loop-game.js восстанавливает дату, страны, экономику, очередь приказов, директивы и состояние мира при исключении во время хода.
Сохранение успешного хода выполняется после результата ИИ.
Это не возврат гостевой квоты или оплаченного API-запроса: удалённое списание может уже произойти.
Полная проверка допустимости EFFECTS и идемпотентность сервера остаются отдельной работой.

Проверены на моках:
- отсутствие продвижения хода без подключения;
- подтверждение собственного ключа и очистка поля;
- передача openai/gpt-6-luna в реальном по форме payload;
- ошибка API прерывает обработку хода;
- восстановление подключения после неудачного Anonymous Sign-in;
- передача модели серверу аккаунта;
- отказ от незаметной подмены модели в гостевом режиме;
- диагностика отсутствующей функции;
- восстановление состояния для недели, месяца и периода при ошибке;
- успешное завершение этих трёх вариантов с одним сохранением.

Проверены синтаксис и опубликованные исходники. Оплаченный живой запрос, настоящий браузер и развёрнутый Supabase в этой сессии не проверены.
Функции Supabase этим обновлением не развёрнуты: доступны только GitHub-инструменты.
